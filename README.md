# tare-hub — Dark Red Developer Profile

A standalone, responsive recreation of a GitHub-style developer profile using plain HTML, CSS, and JavaScript.

## Features

- Black and crimson visual theme with red glow accents
- Custom SVG mountain backdrop and stylized avatar illustration
- Responsive profile sidebar and navigation
- Technology cards, profile intro, badges, and about section
- GitHub statistics-style panels and language bars
- Generated decorative contribution activity grid
- Featured project card and repository links
- Search interaction, demo follow button, and rotating intro text
- No build tools or JavaScript frameworks required

## Run locally

1. Download or clone this folder.
2. Keep `index.html`, `style.css`, `script.js`, and the `assets` folder together.
3. Open `index.html` in a browser.

For a local development server in VS Code, install the Live Server extension and choose **Open with Live Server**.

## Customize

- Change your display name and profile copy in `index.html`.
- Update project links to match your real repositories.
- Edit colors in the `:root` section at the top of `style.css`.
- Replace `assets/mountain-bg.svg` with your own background artwork if desired.

## Notes

This is a standalone website inspired by GitHub's interface, not a custom GitHub README. The follower button is a local demo interaction, and the contribution grid and statistics are illustrative placeholders rather than live GitHub data.

Google Fonts are loaded remotely; the site still works with system font fallbacks when offline.
